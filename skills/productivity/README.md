# Productivity

General workflow tools, not code-specific.

## User-invoked

Reachable only when you type them.

- **[skill-improvement](./skill-improvement/SKILL.md)**: Reviews an existing agent skill and takes it to a fixed bar: contract, gate, evals, audit. Run it deliberately, not mid-task.
- **[stoneman](./stoneman/SKILL.md)**: Compresses every reply to payload only. Code, paths, errors, numbers, and negations stay verbatim. Apache-2.0, derived from ultracave.

## Model-invoked

Model- or user-reachable.

- **[prompt-engineer](./prompt-engineer/SKILL.md)**: Turns a rough request into one finished prompt for a target AI model. Also critiques, tests, and improves prompts.
- **[deep-research](./deep-research/SKILL.md)**: Researches a question into one cited report that stands alone, with an evidence ledger, named gaps, and named conflicts.
- **[podcast-script](./podcast-script/SKILL.md)**: Turns a report or raw notes into a podcast script and the plain text a text-to-speech model reads.
- **[podcast-host-personas](./podcast-host-personas/SKILL.md)**: Builds one gated, machine-readable host persona for a show.
- **[policy-review](./policy-review/SKILL.md)**: Reads a privacy policy or terms of service against a personal posture and reports the flags in a short summary.
- **[adr](./adr/SKILL.md)**: Writes one architecture decision record as a new record, an in-place edit, an amendment or a successor, and reviews a record against twenty-one checks.
