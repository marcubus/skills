# stoneman

Answers in payload only, over a floor that keeps code, numbers, and negations verbatim.

Type `/stoneman` to start. It stays on for the session until "stop stoneman" or "normal mode".

**Use it when** you read fast and want payload only.

**Skip it for** onboarding and anything other humans will read. stoneman writes warnings, irreversible steps, and questions as plain prose, per [Escape](./SKILL.md#escape).

No length number is claimed here. Upstream ultracave [measured](https://github.com/JuliusBrussee/caveman/blob/a192894723a8f47e7f504c7b5041967ff1f18e55/skills/ultracave/README.md) 35% fewer output tokens at the median than a plain concise control, on one model, ten prompts, one run; nothing here re-measures that, and it says nothing about correctness.
