No. 4 workers on 4-core VM already fill the cores. SQLite WAL: many readers, one writer. Writes serialized by the writer lock, so the ceiling is that single writer's rate, about 90 requests per second. Worker count does not enter it. 16 workers: more processes contending for the same writer lock, more context switching, no extra write parallelism. Throughput stays flat or drops. Keep WAL; do not change the journal mode.
