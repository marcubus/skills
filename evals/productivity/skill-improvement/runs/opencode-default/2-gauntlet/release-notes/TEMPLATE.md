# Template

Nine sections, in this order. Every section appears, even when empty.

## 1. Version

The version and the date.

## 2. Summary

One sentence on what this release is for.

## 3. Added

New capability.

## 4. Changed

Different behaviour in something that already existed.

## 5. Fixed

A defect that no longer reproduces.

## 6. Removed

Something that is gone.

## 7. Deprecated

Something that still works and will not.

## 8. Upgrade notes

What the reader has to do, when the bump is major.

## 9. Compare link

The link between this version and the last.
